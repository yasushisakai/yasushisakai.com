# LLM 合議で多数決を超えろ!

各モデルが自分の自信度を測り、不安に応じて仲間を頼る委任型の集約法を使って12,032問の標準テスト解かせたら、多数決を +2.24ポイント上回りました（p ≈ 1.0×10⁻¹⁴）。LLMに同じ問題を何度も解かせ、多数決で答えを決めるのがいまの標準的なやり方だけど、10対6で多数決の結果が誤答でも、少数派の推論に賛同が集まって、結果が逆転する場合があることがわかりました。モデルが自分の"わきまえ"がわかっていれば勝つという仮説が強い。
いまは1モデル・1ベンチですが、複数モデル・複数ベンチでの検証をしてて結果が出るのが楽しみ。
🔗 arxiv.org/abs/2606.08098
